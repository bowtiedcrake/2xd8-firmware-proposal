# 2XD8 Firmware Proposal

This repo contains a proposal for hardware vendors: firmware that lets users manually verify their device's dice rolls instantly, using nothing but a paper booklet.

The idea is adapted from BowTiedCrake's [2XD8 Entropy Booklet](https://x.com/bowtiedcrake/status/2084493937025176048).

## Contents

- `2xd8-workflow-demo.html` — interactive walkthrough of the proposed verification workflow
- `booklet-pages/` — entropy booklet page images referenced by the demo
