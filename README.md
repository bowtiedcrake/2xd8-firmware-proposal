# 2XD8 Firmware Proposal

This repo hosts a user workflow demo used in an article proposal for hardware vendors: firmware that lets users manually verify their device's dice rolls instantly, using nothing but a paper booklet.

The idea is adapted from BowTiedCrake's [2XD8 Entropy Booklet](https://x.com/bowtiedcrake/status/2084493937025176048) ([GitHub repo](https://github.com/bowtiedcrake/2xd8-entropy-booklet)).

## Contents

- `index.html` — interactive walkthrough of the proposed verification workflow ([live demo](https://bowtiedcrake.github.io/2xd8-firmware-proposal/))
- `booklet-pages/` — entropy booklet page images referenced by the demo
